# PGY 一般醫學長期導師評核平台

奇美醫療財團法人奇美醫院「一般醫學長期導師評核表」線上化平台（115年1~6月）。

## 功能

三種身分、三階段簽核流程：

1. **導師**：輸入姓名登入（須在導師名單內），系統自動帶出單位並直接進入自評表；送出後自動以姓名代替簽名，無需重複輸入。
2. **一般科主任**：輸入密碼登入後，可看到所有導師的自評表，逐項評分、填寫回饋；送出時自動簽名（郭妍伶）並帶入當天日期，送交教學部部長。
3. **教學部部長**：輸入密碼登入後，完成最終評分、回饋、學員對導師滿意度（1–5 分）登錄；送出時自動簽名（蘇慧真）並帶入當天日期結案。

### 導師名單維護

導師姓名與單位對照表定義在 `index.html` 內的 `TEACHERS` 常數，格式為 `'姓名': '單位'`，直接編輯即可新增或修改導師資料：

```js
const TEACHERS = {
  '王小明': '一般內科',
  '林美慧': '家庭醫學科',
  // 在此新增更多導師...
};
```

主管密碼定義於同檔案的 `ROLE_PASSWORDS` 常數，主管自動簽名的姓名定義於 `ROLE_SIGNERS` 常數，皆可自行修改。

評量項目（總分 100）：

| 評量內容 | 配分 |
|---|---|
| 1. 是否每月1次與導生座談 | 35 |
| 2. 是否每月繳交座談記錄單 | 20 |
| 3. 當導生出現困難時是否積極幫忙輔導 | 25 |
| 4. 導生若有生活或學習困難是否主動告知教學部 | 20 |

結案後可檢視與原紙本格式一致的完整表單，並可直接列印或另存 PDF。

## 使用方式

直接以瀏覽器開啟 `index.html`，或部署至 GitHub Pages 後以網址存取。進入首頁後選擇身分即可操作。

## 技術說明

- 純前端單一檔案（HTML / CSS / Vanilla JS），無需伺服器與建置流程。
- 資料儲存於瀏覽器 `localStorage`，三種身分於同一瀏覽器內模擬完整簽核流程。
- 密碼與導師名單皆寫在前端原始碼中，僅供流程管控使用，無法防止懂技術的使用者檢視原始碼取得，正式上線請改用後端驗證。
- 若需真正跨使用者、跨裝置的簽核（不同人於不同電腦登入），需另行加上後端資料庫與帳號驗證（例如 Firebase、Supabase 或院內伺服器），目前版本為前端雛形。
