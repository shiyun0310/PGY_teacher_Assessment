# PGY 一般醫學長期導師評核平台

奇美醫療財團法人奇美醫院「一般醫學長期導師評核表」線上化平台（115年1~6月）。

## 功能

三種身分、三階段簽核流程：

1. **導師**：填寫基本資料（姓名、單位）與四項評量之自評得分，簽名後送出。
2. **一般科主任**：於待辦清單中審閱導師自評，逐項評分、填寫回饋並簽名，送交教學部部長。
3. **教學部部長**：完成最終評分、回饋、學員對導師滿意度（1–5 分）登錄並簽名結案。

評量項目（總分 100）：

| 評量內容 | 配分 |
|---|---|
| 1. 是否每月1次與導生座談 | 35 |
| 2. 是否每月繳交座談記錄單 | 20 |
| 3. 當導生出現困難時是否積極幫忙輔導 | 25 |
| 4. 導生若有生活或學習困難是否主動告知教學部 | 20 |

結案後可檢視與原紙本格式一致的完整表單，並可直接列印或另存 PDF。

## 使用方式

直接以瀏覽器開啟 `index.html`，或部署至 GitHub Pages 後以網址存取。進入首頁後選擇身分即可操作。

## 技術說明

- 純前端單一檔案（HTML / CSS / Vanilla JS），無需伺服器與建置流程。
- 資料儲存於瀏覽器 `localStorage`，三種身分於同一瀏覽器內模擬完整簽核流程。
- 若需真正跨使用者、跨裝置的簽核（不同人於不同電腦登入），需另行加上後端資料庫與帳號驗證（例如 Firebase、Supabase 或院內伺服器），目前版本為前端雛形。
