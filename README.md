# PGY 一般醫學長期導師評核平台

奇美醫療財團法人奇美醫院「一般醫學長期導師評核表」線上化平台（115年1~6月）。

## 功能

三種身分、三階段簽核流程：

1. **導師**：輸入人事號登入，系統自動帶出姓名與單位並直接進入自評表；送出後自動以姓名代替簽名，無需重複輸入。（人事號尚未建檔時，輸入姓名亦可登入。）
2. **一般科主任**：輸入密碼登入後，可看到所有導師的自評表，逐項評分、填寫回饋並登錄學員對導師滿意度（1–5 分）；送出時自動簽名（郭妍伶）並帶入當天日期，送交教學部部長。
3. **教學部部長**：輸入密碼登入後，檢視主任評分、回饋與滿意度，完成最終評分與回饋；送出時自動簽名（蘇慧真）並帶入當天日期結案。

評量項目（總分 100）：

| 評量內容 | 配分 |
|---|---|
| 1. 是否每月1次與導生座談 | 35 |
| 2. 是否每月繳交座談記錄單 | 20 |
| 3. 當導生出現困難時是否積極幫忙輔導 | 25 |
| 4. 導生若有生活或學習困難是否主動告知教學部 | 20 |

結案後可檢視與原紙本格式一致的完整表單，並可直接列印或另存 PDF。

## 兩種運作模式

| 模式 | 資料存放 | 適用情境 |
|---|---|---|
| Google Sheets 模式 | Google 試算表（跨電腦共用） | 正式使用：導師、主任、部長各自在自己電腦操作 |
| 單機測試模式 | 瀏覽器 localStorage | 開發測試、展示（`API_URL` 留空即為此模式） |

## Google Sheets 資料庫設定（正式使用請照此設定）

1. **建立試算表**：到 [Google Sheets](https://sheets.google.com) 新增一份空白試算表，名稱自訂（例如「PGY導師評核資料庫」）。
2. **貼上後端程式**：試算表上方選單「擴充功能 → Apps Script」，刪除編輯器內預設內容，貼上本專案 [`google-apps-script/Code.gs`](google-apps-script/Code.gs) 的全部內容後儲存。
3. **部署為網路應用程式**：右上角「部署 → 新增部署作業」，類型選「網頁應用程式」：
   - 執行身分：**我**
   - 具有存取權的使用者：**任何人**
   - 按「部署」，依畫面完成授權（會警告未經驗證，選「進階 → 前往（不安全）」繼續即可，這是自己的程式）。
4. **複製網址**：複製部署完成後顯示的網頁應用程式網址（`https://script.google.com/macros/s/…/exec`）。
5. **填入前端**：打開 `index.html`，把網址貼到最上方的 `API_URL` 常數：
   ```js
   const API_URL = 'https://script.google.com/macros/s/…/exec';
   ```
6. **初始化工作表**：用瀏覽器開啟該網址一次，看到「API 運作中」即成功，系統會自動建立 `teachers` 與 `assessments` 兩張工作表。
7. **建立導師名單**：在 `teachers` 工作表中逐列填入導師資料：

   | 姓名 | 單位 | 停用請填N | 人事號 | 座談記錄單連結 |
   |---|---|---|---|---|
   | 王小明 | 一般內科 | | A12345 | |
   | 林美慧 | 家庭醫學科 | | A67890 | |

   第 3 欄留空即為啟用，填 `N` 表示停用（離職或本期不參與）。第 4 欄人事號是導師登入用的帳號。第 5 欄為座談記錄單連結，可用下方工具自動填入。第 1 列的標題文字可自由改寫，程式是依欄位位置讀取。

### 導師座談記錄單連結

平台會在導師自評表、主任／部長評核表與檢視頁顯示「開啟記錄單」按鈕，讓三種身分都能在評分前先看記錄單。**導師只會看到自己的記錄單**（伺服器端即依姓名過濾，不會回傳其他人的資料）。

設定方式：

1. 把 19 份座談記錄單放進雲端硬碟的**同一個資料夾**，檔名需包含導師姓名（例如 `王小明_導師座談記錄單_1-6月`）。
2. 開啟該資料夾，從網址列複製資料夾 ID：`https://drive.google.com/drive/folders/【這一段】`。
3. 在 Apps Script 編輯器把 ID 填入 `Code.gs` 最上方的 `MEETING_FOLDER_ID`。**請只填在 Apps Script 編輯器中，不要提交進本 repo**——這是公開 repo，資料夾 ID 一旦公開，等同所有記錄單對外開放。
4. 編輯器上方函式下拉選單選擇 **`fillMeetingLinks`**，按「執行」。系統會依檔名比對姓名，自動把連結填進 `teachers` 工作表第 5 欄；執行紀錄會列出成功筆數與查無檔案的姓名。
5. 設定資料夾的共用權限為「知道連結的任何人皆可檢視」，否則其他人點連結會顯示沒有權限。日後新增檔案只要重跑一次 `fillMeetingLinks` 即可。

若某位導師的檔案命名特殊、自動比對不到，直接在第 5 欄手動貼上連結也可以。

評核資料會自動寫入 `assessments` 工作表，欄位包含：四項自評分數與總分、主任四項評分／總分／回饋／滿意度、部長四項評分／總分／回饋、狀態、三方簽核日期，可直接在試算表中檢視或匯出報表。

### 修改密碼或簽名人

打開 Apps Script 編輯器，修改 `Code.gs` 最上方的 `PASSWORDS`（主任 940963／部長 010101）與 `SIGNERS`（郭妍伶／蘇慧真）。**修改後需「部署 → 管理部署作業 → 編輯（鉛筆圖示）→ 版本選「新版本」→ 部署」才會生效**，網址不變。

## 使用方式

直接以瀏覽器開啟 `index.html`，或部署至 GitHub Pages 後以網址存取。進入首頁後選擇身分即可操作。

## 技術說明

- 前端為純單一檔案（HTML / CSS / Vanilla JS），無需建置流程；後端為 Google Apps Script（免費），資料存於 Google 試算表。
- 單機測試模式下，導師名單與密碼使用 `index.html` 內的 `TEACHERS`、`ROLE_PASSWORDS` 常數；Google Sheets 模式下由 `teachers` 工作表與 Apps Script 的 `PASSWORDS` 驗證（密碼不出現在前端原始碼）。
- 讀寫資料時前端會帶上身分：導師只會取回自己的評核紀錄與座談記錄單連結，主任／部長需通過密碼驗證才能取得全部資料，過濾在伺服器端完成。
- 密碼驗證僅供流程管控，並非高強度資安防護；評核資料的實際保護來自 Google 試算表本身的存取權限（僅擁有者可開啟）。
